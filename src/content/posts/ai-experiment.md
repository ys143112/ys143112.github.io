## 실험의 질문

이 글은 실제 실험 결과가 아닌 기록용 샘플 템플릿입니다. 먼저 이번 실험에서 확인하고 싶은 질문을 한 문장으로 적습니다.

## 재현에 필요한 조건

- 사용한 모델 또는 도구와 버전
- 입력한 프롬프트 또는 데이터
- 변경한 설정과 고정한 설정
- 실행한 날짜
- 결과를 판단할 기준

## 결과를 비교하기

| 비교 항목 | 첫 번째 시도 | 수정한 시도 |
| --- | --- | --- |
| 입력 조건 | 직접 입력 | 직접 입력 |
| 관찰한 결과 | 직접 입력 | 직접 입력 |
| 개선할 점 | 직접 입력 | 직접 입력 |

## 해석과 다음 질문

한 번의 결과로 일반적인 결론을 내리기보다, 확인한 범위와 아직 모르는 부분을 구분해 적습니다. 실패한 시도도 다음 실험을 설계하는 자료가 됩니다.
